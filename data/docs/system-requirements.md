# 推奨環境

ハルクロックを使うためのブラウザ・スマホ・タブレットの推奨環境です。推奨環境以外では、表示や動作が正しくないことがあります。

## パソコンのブラウザ

| OS | ブラウザ |
| --- | --- |
| Windows 10 / 11 | Google Chrome、Microsoft Edge（どちらも最新版） |
| macOS（最新の2バージョン） | Google Chrome、Safari（どちらも最新版） |

- Internet Explorer は使えません
- ブラウザの Cookie と JavaScript を有効にしてください
- 画面の幅は 1280px 以上を推奨します

## スマホアプリ

| OS | 対応バージョン |
| --- | --- |
| iOS | 16 以上 |
| Android | 11 以上 |

- アプリは App Store と Google Play で「ハルクロック」と検索してインストールします
- 位置情報を記録する設定のときは、アプリに位置情報の利用を許可してください
- スマホのブラウザからも打刻できますが、アプリの利用をおすすめします

## 共有タブレット

事業所の入口などに置いた1台のタブレットで、複数の従業員が打刻できます。

| 機器 | 対応バージョン |
| --- | --- |
| iPad | iPadOS 16 以上 |
| Android タブレット | Android 11 以上 |

- 共有タブレットは、ハルクロックのアプリの「共有タブレットモード」で使います
- IC カード打刻には、別売りの専用 IC カードリーダーが必要です（スタンダード以上）

## 通信環境

- インターネットに接続できる環境が必要です
- 会社のネットワークで通信を制限している場合は、ハルクロックのドメインへの通信（HTTPS）を許可してください
- 推奨環境を満たしていても、お客さまの社内ネットワーク・端末の設定による不具合の解決は、サポートの対象外です
