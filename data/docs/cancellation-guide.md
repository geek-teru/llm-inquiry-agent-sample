# 解約の手順

ハルクロックの解約の申請期限、手順、解約後のデータの扱いをまとめた資料です。

## 解約の申請期限

ハルクロックの解約は、**解約する月の前月20日まで** に申請してください。その月の末日で解約になります。

| 解約したい日 | 申請の期限 |
| --- | --- |
| 6月30日 | 5月20日 |
| 9月30日 | 8月20日 |
| 12月31日 | 11月20日 |

- 前月20日を過ぎて申請した場合は、その翌月の末日での解約になります（例: 5月25日に申請すると、7月31日で解約）
- 申請期限の20日が土日祝日でも、期限は変わりません。管理画面からの申請は24時間受け付けています

## 解約の申請方法

解約は、管理画面から契約の管理者が申請します。電話・メール・チャットでの解約の申請はお受けしていません。

1. 管理画面の **設定 > 契約 > 解約の申請** を開きます
2. 解約する月を選びます（選べるのは、申請期限に間に合う月だけです）
3. 解約の理由を選び（任意）、「解約を申請する」を押します
4. 契約の管理者のメールアドレスに、解約の受付メールが届きます

- 申請した解約は、解約日の前日までなら同じ画面から取り消せます

## 年払いの途中での解約

年払いの契約を途中で解約した場合、契約は **更新日の前日まで** 続きます。残りの月数分の料金は返金しません。

- 年払いの契約で解約を申請すると、更新日の前日が解約日になります
- 解約日までは、これまでどおりすべての機能を使えます

## 解約後のデータ

解約日から **90日** を過ぎると、登録したデータ（従業員・打刻・申請・集計）をすべて削除します。削除したデータは元に戻せません。

- 解約日のあと 90日間は、管理画面にログインして CSV でデータを取り出せます（打刻・申請などの登録や変更はできません）
- 取り出し方は「CSV 出力の操作マニュアル」をご覧ください
- 90日より前にデータの削除を希望する場合は、サポート窓口にご連絡ください

## 解約前に確認すること

- 解約の申請期限（前月20日）に間に合っているか
- 最後の月の集計と締めが終わっているか。解約日のあとは月次の締めができません
- 給与ソフトなどに渡す CSV を取り出したか
- 年払いの場合、更新日の前日まで契約が続くこと
