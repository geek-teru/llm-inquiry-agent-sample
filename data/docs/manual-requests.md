# 勤怠申請の操作マニュアル

従業員が行う勤怠の申請（打刻修正・残業・休日出勤・休暇）の方法をまとめた資料です。勤怠申請は全プランで使えます。

## 申請の種類

| 申請 | 使う場面 |
| --- | --- |
| 打刻修正 | 打刻を忘れた、間違えた時刻で打刻した |
| 残業 | 所定の労働時間を超えて働く（事前・事後） |
| 休日出勤 | 休日に出勤する |
| 休暇 | 有給休暇、特別休暇（慶弔休暇など、会社が設定した休暇）を取る |

- 会社がどの申請を使うかは、管理者が **設定 > 申請** で決めます

## 申請の方法

1. Web は画面左の **申請**、スマホアプリは画面下の **申請** を開きます
2. 「新しい申請」を押し、申請の種類を選びます
3. 日付・時刻・理由を入力し、「申請する」を押します
4. 承認者に通知が届きます。申請の状況は **申請 > 申請一覧** で確認できます

## 打刻修正の申請

打刻を忘れた日や、間違えた打刻を正しい時刻に直します。

1. **申請 > 新しい申請 > 打刻修正** を選びます
2. 修正する日を選ぶと、その日の打刻が表示されます
3. 正しい時刻を入力するか、足りない打刻（例: 退勤）を追加し、理由を入力して申請します

- 承認されるまでは、元の打刻のまま集計されます
- 月次の締めのあとは、その月の打刻修正の申請はできません。管理者に修正を依頼してください

## 残業・休日出勤の申請

- 残業の申請は、残業する前（事前）でも、した後（事後）でもできます。事前の申請を必須にするかは、管理者が **設定 > 申請** で決めます
- 休日出勤の申請は、出勤する休日と予定の時間を入力します
- 申請した時間と実際の打刻が違う場合、集計には実際の打刻の時間を使います

## 休暇の申請

1. **申請 > 新しい申請 > 休暇** を選びます
2. 休暇の種類（有給休暇・特別休暇）と、取る日を選びます
3. 有給休暇は、全日・半日（午前 / 午後）・時間単位から選びます（時間単位は、会社が設定している場合のみ）

- 有給休暇の残日数は、申請の画面に表示されます
- 残日数を超える有給休暇は申請できません

## 申請の取り消し

- 承認される前の申請は、**申請 > 申請一覧** から本人が取り消せます
- 承認されたあとの申請を取り消したい場合は、承認者に差し戻しを依頼するか、改めて打刻修正などを申請してください

## 差し戻された申請

承認者が申請を差し戻すと、申請した本人にメールで通知が届きます。

- 差し戻された申請は、**申請 > 申請一覧** から内容を直して再申請できます
- 差し戻しの理由は、申請の詳細画面に表示されます
