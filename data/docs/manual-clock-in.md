# 打刻の操作マニュアル

ハルクロックの打刻（出勤・退勤・休憩）の方法をまとめた資料です。打刻は全プランで使えます。

## 打刻の種類

ハルクロックでは、出勤・退勤・休憩開始・休憩終了の4種類を打刻します。

- 休憩を打刻しない場合は、就業ルールで設定した休憩時間を自動で差し引きます
- 1日に複数回の出勤・退勤（中抜け）も打刻できます

## Web ブラウザでの打刻

1. パソコンのブラウザでハルクロックにログインします
2. ホーム画面の「出勤」「退勤」「休憩開始」「休憩終了」のボタンを押します
3. 画面上部に打刻した時刻が表示されたら完了です

- 打刻の時刻は、ハルクロックのサーバーの時刻で記録します。パソコンの時計がずれていても影響しません

## スマホアプリでの打刻

1. スマホアプリ「ハルクロック」を開き、ログインします
2. 画面中央の打刻ボタンを押し、出勤・退勤・休憩を選びます
3. 「打刻しました」と表示されたら完了です

- 電波が届かない場所で打刻した場合は、アプリが打刻を一時的に保存し、通信が戻ったときに送信します。記録される時刻は、ボタンを押した時刻です
- 通信が戻らないまま 24時間がたつと、保存した打刻は送信されません。打刻修正の申請をしてください

## スマホ打刻の位置情報

スマホアプリでの打刻に、位置情報（打刻した場所）を記録できます。記録するかどうかは管理者が設定します。

1. 管理者が **設定 > 打刻方法 > スマホアプリ** で「位置情報を記録する」をオンにします
2. 従業員のスマホで、ハルクロックのアプリに位置情報の利用を許可します

- 位置情報は、打刻した瞬間の場所だけを記録します。打刻していない時間の位置は記録しません
- 記録した場所は、管理者が **打刻 > 打刻一覧** の地図のアイコンから確認できます
- 位置情報の利用を許可していないスマホでは、位置情報なしで打刻されます

## 共有タブレットでの打刻

事業所に置いた共有タブレット1台で、複数の従業員が打刻できます。

1. 管理者が、タブレットのアプリで **共有タブレットモード** をオンにします（管理者のログインが必要です）
2. 従業員は、タブレットの画面で自分の従業員番号を入力するか、名前を選びます
3. 4桁の打刻用暗証番号を入力し、打刻の種類を選びます

- 打刻用暗証番号は、従業員がスマホアプリまたは Web の **個人設定 > 打刻用暗証番号** で設定します
- 共有タブレットモードを解除するには、管理者のパスワードが必要です

## 打刻を忘れた・間違えたとき

打刻を忘れた場合や、間違えて打刻した場合は、従業員が **打刻修正の申請** をします。承認されると打刻が修正されます。

- 申請の方法は「勤怠申請の操作マニュアル」をご覧ください
- 月次の締めのあとは、従業員からの打刻修正の申請はできません。管理者が修正します
