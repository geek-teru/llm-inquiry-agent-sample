# プロプランの機能の操作マニュアル（複数事業所・API・SSO・操作ログ）

プロプランだけで使える、複数事業所・API・シングルサインオン（SSO）・操作ログの設定方法をまとめた資料です。スタータープラン・スタンダードプランでは使えません。

## 複数事業所

プロプランでは、1つの契約の中で事業所を分け、事業所ごとに就業ルールと締め日を設定できます。

1. **設定 > 事業所** を開き、「事業所を追加」を押します
2. 事業所名を入力し、その事業所の就業ルールと締め日を設定します
3. **従業員 > 従業員の詳細** で、従業員の所属する事業所を選びます

- 事業所ごとに管理者を設定できます。事業所の管理者は、自分の事業所の従業員のデータだけを見られます
- 料金は、すべての事業所のユーザー数を合計して計算します
- プロプラン以外では事業所を分けられません。複数の事業所がある場合も、1つの就業ルール・締め日で管理します

## API

プロプランでは、打刻データと集計データを取得する API を使えます。

1. 管理者が **設定 > API** を開き、「API キーを発行」を押します
2. 表示された API キーを控えます。API キーは、発行したときに一度だけ表示されます
3. API の仕様書は、同じ画面の「API 仕様書」から見られます

- 取得できるのは、打刻データと集計データです。API からデータを登録・変更することはできません
- API キーは何個でも発行でき、不要になったキーは同じ画面で無効にできます
- API を使った連携の作成や、連携先のシステムの設定はサポートの対象外です

## シングルサインオン（SSO）

プロプランでは、SAML 2.0 に対応した ID プロバイダーを使って、シングルサインオンでログインできます。

1. 管理者が **設定 > SSO** を開き、表示されるハルクロックの情報（エンティティ ID と ACS の URL）を ID プロバイダーに登録します
2. ID プロバイダーのメタデータ（XML）を、ハルクロックの同じ画面にアップロードします
3. 「テストログイン」で SSO でログインできることを確かめてから、「SSO を有効にする」を押します

- SSO を有効にしても、管理者1人以上はパスワードでもログインできるようにしておくことをおすすめします（ID プロバイダーの障害に備えるため）
- ID プロバイダー側の設定方法は、ID プロバイダーの提供元にお問い合わせください

## 操作ログ

プロプランでは、管理者の設定変更とデータ修正の履歴を、**1年分** 確認できます。

1. **設定 > 操作ログ** を開きます
2. 期間、操作した管理者、操作の種類で絞り込みます
3. 必要なら「CSV 出力」で書き出します

- 記録するのは、管理者による設定の変更と、打刻・申請・集計のデータの修正です。従業員の打刻や申請そのものは記録しません
- 1年を過ぎた操作ログは自動で削除します

## プロプランから下位プランに変更したとき

プロプランからスタンダードプランなどに変更すると、適用日から次のようになります。

- 複数事業所: 事業所の区分が使えなくなり、すべての従業員が1つの就業ルール・締め日で管理されます。どの就業ルールを残すかは、変更の前に選びます
- API: 発行した API キーは使えなくなります
- SSO: SSO でのログインができなくなり、パスワードでのログインに戻ります
- 操作ログ: それまでの操作ログは見られなくなります。必要な場合は、変更の前に CSV で出力してください
