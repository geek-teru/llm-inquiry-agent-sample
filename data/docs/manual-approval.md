# 承認フローの操作マニュアル

勤怠申請の承認フローの設定方法と、承認者の操作をまとめた資料です。承認フローは全プランで使えますが、設定できる段数がプランによって違います。

## プランごとの承認の段数

| プラン | 承認の段数 |
| --- | --- |
| スターター | 1段階 |
| スタンダード | 2段階まで |
| プロ | 3段階まで |

- 例: スタンダードプランでは「所属長 → 人事担当」の2段階の承認を設定できます
- スタータープランでは、1人（または1つのグループ）の承認で申請が確定します

## 承認フローの設定

承認フローは、管理者が **設定 > 承認フロー** で設定します。

1. 設定 > 承認フロー を開き、「承認フローを追加」を押します
2. 対象の申請の種類（打刻修正・残業・休日出勤・休暇）と、対象の所属を選びます
3. 1段目の承認者を選びます。スタンダード以上では「段を追加」で2段目以降を追加できます
4. 「保存する」を押します

- 承認者には、従業員1人か、承認グループ（複数人のうち誰か1人が承認すればよい）を指定できます
- 承認フローを設定していない申請は、管理者が承認します
- 承認フローを変更しても、すでに申請中の申請には、申請したときのフローが使われます

## 承認者の操作

1. 申請が届くと、承認者にメールで通知が届きます
2. Web は画面左の **承認**、スマホアプリは画面下の **承認** を開きます
3. 申請の内容を確認し、「承認」または「差し戻し」を押します。差し戻すときは理由を入力します

- 複数の申請をまとめて承認するには、承認一覧で申請を選び「まとめて承認」を押します
- 2段階以上のフローでは、前の段の承認者が承認すると、次の段の承認者に通知が届きます

## 承認者が不在のとき

承認者が休暇などで不在のときは、代理の承認者を設定できます。

1. 承認者本人が **個人設定 > 代理承認者** で、代理の人と期間を設定します
2. 期間中の申請は、代理の承認者にも届きます

- 承認者が退職した場合は、管理者が **設定 > 承認フロー** で承認者を変更してください。変更しないと、申請が承認されないまま残ります

## 下位プランに変更したとき

承認の段数が少ないプランに変更すると、適用日から、上限を超える段は使えなくなります。

- 例: スタンダードからスターターに変更すると、2段目の承認は自動で省かれ、1段目の承認で申請が確定します
- 変更の前に、承認フローを見直してください
