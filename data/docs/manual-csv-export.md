# CSV 出力の操作マニュアル

集計結果や打刻データを CSV で出力する方法をまとめた資料です。CSV 出力は全プランで使えます。

## 出力できるデータ

| データ | 出力する画面 |
| --- | --- |
| 月次の集計結果（従業員ごとの合計） | 勤怠集計 > CSV 出力 |
| 日ごとの勤怠明細 | 勤怠集計 > CSV 出力 |
| 打刻の一覧 | 打刻 > 打刻一覧 > CSV 出力 |
| 申請の一覧 | 申請 > 申請一覧 > CSV 出力 |
| 有給休暇の取得状況 | 有給休暇 > 取得状況 > CSV 出力 |
| シフト表（スタンダード以上） | シフト > シフト表 > CSV 出力 |
| 従業員の一覧 | 従業員 > CSV 出力 |

## 集計結果の CSV 出力

1. **勤怠集計 > CSV 出力** を開きます
2. 対象の月と、出力するテンプレートを選びます
3. 文字コード（UTF-8 / Shift_JIS）を選び、「出力する」を押します
4. CSV ファイルがダウンロードされます

- 締めていない月も出力できますが、あとでデータが変わる可能性があります。給与ソフトなどに渡す場合は、締めたあとに出力してください
- 従業員が多い場合（500人以上）は、出力に数分かかることがあります。準備ができると、画面とメールでお知らせします

## 出力テンプレートの作成

出力する項目と並び順を、テンプレートとして保存できます。

1. **設定 > CSV テンプレート** を開き、「テンプレートを追加」を押します
2. テンプレート名を入力し、出力する項目を選んで並べ替えます
3. 列の見出しの名前は、項目ごとに変えられます
4. 「保存する」を押します

- テンプレートは何個でも保存できます
- 時間の表し方（「8:30」形式 / 「8.5」の10進数形式）を、テンプレートごとに選べます

## 給与ソフトなどに渡すとき

ハルクロックの CSV 出力は、給与ソフトなどに取り込むためのファイルを作るところまでが範囲です。

- 取り込む側のソフトが求める項目と並び順に合わせて、出力テンプレートを作成してください
- 取り込む側のソフトの操作方法は、そのソフトの提供元にお問い合わせください

## 文字化けするとき

- 表計算ソフトで開いたときに文字化けする場合は、文字コードを Shift_JIS にして出力し直してください
- 取り込む側のソフトが UTF-8 を求める場合は、UTF-8 を選んでください
